FORGE — Racik Skill

FORGE adalah tempat kamu membuat skill: catatan kerja / resep digital yang bisa kamu simpan, pakai ulang, dan bawa ke perangkat mana pun. Panduan ini menjelaskan tahap demi tahap dengan sangat rinci — bukan cuma "klik apa", tapi juga kenapa dan bagaimana tahu kamu berhasil.

01 Pahami dulu: apa itu “skill”?

Dalam SKILL//ORBIT, sebuah “skill” adalah satu file teks bernama SKILL.md yang berisi dua bagian:

  • Metadata (di bagian atas) — “kartu identitas”: nama, deskripsi, versi, penulis, tag. Kenapa penting: ini yang dipakai aplikasi lain / agent untuk mengenali dan mencari skill-mu.
  • Isi / prosedur (di bawah) — resep kerja: kapan dipakai, apa yang dibutuhkan, bagaimana menjalankannya langkah demi langkah, dan bagaimana memastikan hasilnya benar.

Mengapa format file? Karena teks sederhana itu portable (bisa dibaca di mana pun) dan standar (tidak terikat satu aplikasi). Di FORGE kamu membentuk file ini lewat form yang mudah, jadi tidak perlu hafal Markdown rumit.

02 Buka FORGE

1

Masuk dari Beranda

Buka aplikasi. Di halaman awal ada tiga kartu besar; klik kartu “FORGE — Racik skill”. Bisa juga klik tab FORGE di menu atas.

Yang akan kamu lihat: halaman terbagi dua — kiri adalah area mengisi/meracik, kanan adalah PRATINJAU (hasil file yang sedang terbentuk).

Penting: ingat pembagian ini. Kiri = tempat bekerja, kanan = cermin hasilnya. Pratinjau otomatis berubah setiap kali kamu mengedit di kiri.

CEK BERHASIL Kamu melihat form di kiri dan kotak besar bertuliskan “PRATINJAU” di kanan.

03 Pilih bahan dasar — ada 3 cara

2

Cara A — dari GALERI (paling mudah)

Di kiri bagian atas ada blok “Galeri” berisi kumpulan pola skill siap pakai (mis. rekap keuangan, konten, prosedur). Klik satu pola, lalu tekan “Terapkan”.

Kenapa pakai ini: form langsung terisi struktur yang rapi sebagai titik mulai, jadi kamu hanya menyesuaikan — paling cepat untuk pemula.

CEK BERHASIL Form kiri terisi otomatis dan pratinjau kanan berubah sesuai pola itu.

3

Cara B — dari repo GitHub (pakai “Racik”)

Di blok “Telusur GitHub”, ketik kata kunci (mis. perencanaan atau proposal) lalu tekan Cari. Pada hasil yang kamu suka, tekan “Racik”.

Yang terjadi di balik layar: aplikasi menarik konten skill publik itu dan menjadikannya draf yang siap kamu ubah-ubah. Repo yang tidak punya file SKILL.md tetap tidak menggagalkanmu — sistem menyusun draf dari README-nya. Tidak pernah buntu.

Perhatian: draf hasil Racik dari repo daftar (kumpulan link, bukan satu skill) biasanya cuma kerangka umum — tag direset kosong, jadi isi sendiri tag dan tulis resepnya agar benar-benar berguna.

CEK BERHASIL Muncul banner hijau “MERACIK DI SINI” di kiri, nama repo tertulis, dan form terisi draf. Kamu bisa mulai mengedit.

4

Cara C — dari nol (manual)

Kosongkan semua isian lalu ketik sendiri: nama, deskripsi (singkat, ≤60 huruf), tag, penulis, dan versi.

Kapan cocok: ketika kamu sudah paham persis resep yang mau ditulis dan tidak butuh contoh.

04 Tulis isi skill (bagian terpenting)

5

Isi kolom “Cara kerja / isi” dengan urutan langkah yang jelas

Tulis instruksi sebagai urutan sederhana: mulai dari apa → lakukan apa → kapan selesai / bagaimana tahu benar. Bayangkan kamu menjelaskan kepada orang yang belum pernah melakukannya.

Cara menulis yang disarankan:
  • Gunakan kalimat pendek yang memerintah (“Buka…”, “Isi…”, “Catat…”).
  • Pecah jadi paling banyak 3–5 langkah. Satu langkah = satu tindakan.
  • Di akhir, tulis kriteria selesai: hasil seperti apa yang membuktikan langkahmu benar.

Tips: skill yang baik itu tajam — fokus satu pekerjaan utama, bukan sepuluh hal sekaligus. Kalau kepanjangan, pecah jadi beberapa skill.

6

Pilih “perilaku” & “alat” (toggle)

Di bawah kolom isi ada pilihan perilaku (berapa langkah, apakah berakhir dengan cek) dan alat (terminal / API / file) yang menggambarkan bagaimana skill itu dipakai. Klik untuk mengaktifkan/menonaktifkan.

Kenapa: metadata ini membantu aplikasi lain memutuskan kapan dan bagaimana memakai skill-mu dengan benar.

05 Cek PRATINJAU

7

Periksa hasilnya di sisi kanan

PRATINJAU menampilkan file SKILL.md yang akan kamu simpan. Baca dari atas ke bawah: apakah metadata rapi? Apakah isi sudah mencakup seluruh langkah yang kamu maksud?

Catatan: pratinjau bersifat hanya-lihat. Kalau ada yang kurang pas, jangan diedit di sini — ubah di kolom kiri, pratinjau akan mengikuti.

CEK BERHASIL Pratinjau mencerminkan semua isianmu dan tampak rapi tanpa bagian yang janggal.

06 SIMPAN

8

Simpan ke koleksi & (opsional) cloud

Tekan “SIMPAN” di kanan atas panel pratinjau. Skill tersimpan ke ARSIP (koleksi di perangkat ini). Bila kamu sudah masuk akun online, kamu juga bisa menyinkronkan ke server agar bisa diambil di perangkat lain.

Alternatif lain: tombol Salin (copy file ke clipboard) dan Unduh (simpan sebagai berkas .SKILL.md) — berguna kalau mau membagikan atau menyimpan di luar aplikasi.

CEK BERHASIL Muncul konfirmasi tersimpan, dan skill muncul di daftar ARSIP.

07 Cara paling cepat selesai (jalan pintas)

  1. Buka FORGE.
  2. Di Galeri, klik pola yang paling mirip kebutuhanmu → Terapkan.
  3. Ganti nama & deskripsi, ketik langkah-langkahmu di kolom isi.
  4. Lirik pratinjau → SIMPAN.

Hasil: biasanya kurang dari 2 menit untuk skill pertamamu.

08 Di balik layar

  • Racik menghubungi raw.githubusercontent.com, mencoba membaca file SKILL.md, lalu jatuh kembali ke README.md bila tak ada — itulah kenapa tidak pernah kosong.
  • Panel Galeri diisi pola bawaan; Radar menarik bintang asli dari GitHub API.
  • Simpan ke ARSIP menulis ke penyimpanan lokal perangkat; simpan ke cloud (setelah login) mengirim ke server SKILL//ORBIT lewat API yang diamankan.

09 Contoh use case nyata

USE CASE 1 · Pembukuan usaha kecil

Pelaku usaha di Sekadau ingin rekap keuangan warung mingguan tanpa ribet.

  • Pilih GALERI → pola “rekap-keuangan” → Terapkan.
  • Ganti nama jadi rekap-keuangan-warung, deskripsi “Rekap keuangan & untung-rugi warung otomatis.”
  • Tulis langkah: catat omzet tiap malam → isi kolom tetap → hitung selisih → simpan ringkasan.
  • Pratinjau → rapi → SIMPAN.

USE CASE 2 · Prosedur kerja tim WiFi

Membuat checklist pemasangan WiFi agar tim konsisten di tiap pelanggan.

  • Dari nol: nama = checklist-instalasi-wifi.
  • Langkah: survei lokasi → pasang AP → konfigurasi → tes sinyal → catat data pelanggan.
  • Terakhir tulis kriteria selesai (sinyal stabil di semua titik).
  • Simpan; bisa di-share ke rekan sebagai acuan baku.

USE CASE 3 · Paket konten harian

Menghasilkan 5 ide konten dari satu topik setiap minggu.

  • Gunakan “Racik” dari repo publik bertema konten yang populer (lihat RADAR).
  • Ubah isinya jadi prompt: “Buat 5 ide konten tentang topik X.”
  • Simpan sebagai skill yang bisa dipakai berulang.

10 Tanya-jawab yang sering

Kenapa tag saya jadi kosong setelah Racik?

Karena repo itu tidak menyediakan tag, aplikasi mengosongkannya (bukan memakai tag contoh yang nyasar). Ketik tag-mu sendiri, pisah dengan koma.

Pratinjau tidak bisa diedit, benar?

Benar. Pratinjau hanyalah tampilan. Ubah semua di panel kiri; pratinjau mengikuti otomatis. Itu dirancang agar hasil akhir selalu rapi.

Apa bedanya SIMPAN, Salin, dan Unduh?

SIMPAN → masuk ke ARSIP (koleksi di aplikasi). Salin → menyalin file ke clipboard untuk ditempel ke mana saja. Unduh → menyimpan sebagai berkas .SKILL.md di perangkat.

Apakah skill tersimpan hilang jika tanpa akun?

Tidak, selama disimpan ke ARSIP di perangkat itu, koleksi lokal aman. Akun online hanya untuk backup & pindah perangkat.

Nama skill boleh pakai huruf besar dan spasi?

Sebaiknya huruf kecil, tanpa spasi, pakai tanda - (mis. rekap-keuangan-warung). Rentan bentrok bila memakai spasi/karakter spesial.

11 Glosarium

SKILL.md — file teks hasil racikan, berisi metadata + prosedur.

Metadata — “kartu identitas” di atas file: nama, deskripsi, versi, penulis, tag.

Galeri — kumpulan pola skill siap pakai di panel kiri.

Racik — tombol menarik skill publik dari GitHub menjadi draf yang bisa kamu ubah.

Pratinjau — tampilan kanan yang menunjukkan file akhir secara otomatis.

ARSIP — koleksi semua skill yang sudah kamu simpan.

Tag — label kategori untuk memudahkan pencarian (pisah dengan koma).
