RADAR — Tren Skill

RADAR adalah “peta popularitas”: daftar skill yang sedang banyak dipakai komunitas builder. Jumlah bintangnya nyata dibaca langsung dari API GitHub — bukan angka karangan — sehingga kamu bisa membaca arah yang sedang ramai dan menggali ide untuk skill-mu sendiri.

⏱ ≈ 5–6 menit baca🎯 Semua pemula📡 Bintang asli dari GitHub API

01 Buka RADAR

1

Masuk dari Beranda

Klik kartu “RADAR — tren” atau tab RADAR di menu atas. Setiap kali tab dibuka, aplikasi otomatis memuat data terbaru.

Yang akan kamu lihat: daftar berisi baris-baris skill, masing-masing dengan nama, deskripsi singkat, dan jumlah bintang (★).

CEK BERHASIL Daftar muncul dengan angka bintang — itu berarti koneksi ke GitHub berjalan.

02 Baca daftarnya

2

Apa arti tiap baris

Nama = identitas skill. Deskripsi = satu kalimat tentang fungsinya. Bintang (★) = jumlah orang yang menyimpan/menyukai skill itu di GitHub.

Bagaimana membacanya dengan cerdas:
  • Bintang tinggi → teruji dipakai banyak orang; biasanya formatnya rapi dan stabil.
  • Bintang rendah tapi unik → bisa jadi ide segar yang jarang orang sadari.
  • Perhatikan pola yang berulang antar-skill populer: itulah "cara baku" yang terbukti.

Tips: jangan hanya mengejar yang terpopuler. RADAR berguna untuk menemukan bahasa/cara kerja, bukan sekadar bersaing hitungan bintang.

03 Perbarui angka

3

Tekan REFRESH

Tombol REFRESH menarik angka bintang terkini dari GitHub. Berguna kalau halaman sudah lama terbuka dan kamu mau memastikan angkanya segar.

Kenapa kadang perlu: popularitas berubah cepat. Menyegarkan membantu kamu menangkap pergeseran sebelum memutuskan ide.

04 Telusuri sumbernya

4

Klik salah satu skill

Baris yang bisa diklik membuka repo sumbernya di GitHub di tab baru. Dari situ kamu bisa melihat isi skill-nya, membaca struktur, dan menilai apakah polanya cocok dengan kebutuhanmu.

Kenapa ini berguna: halaman GitHub menunjukkan file asli (mis. SKILL.md/README), riwayat, dan cara penulis menyusunnya — sumber belajar paling autentik.

CEK BERHASIL Tab baru terbuka ke halaman repo GitHub yang sesuai.

05 Ubah tren jadi skill-mu (kunci aplikasi ini)

5

Temukan → tiru alurnya → racik versimu

Ini bagian paling berharga RADAR — memanfaatkannya untuk membuat karya, bukan cuma membaca:

  1. Di RADAR, pilih skill yang menarik perhatianmu, buka repo-nya.
  2. Pelajari struktur & pola-nya (bagian apa saja, bahasa apa, langkah apa).
  3. Buka FORGE → di blok Telusur GitHub, cari repo itu → tekan Racik untuk menjadikannya draf.
  4. Ubah draf jadi versimu sendiri yang lebih cocok untuk kebutuhan/usaha lokalmu.
  5. SIMPAN.

Tips: hasil terbaik lahir dari adaptasi sediri, bukan salin mentah. Ciptakan pola yang kamu senangi, lalu sesuaikan isinya.

06 Di balik layar

  • RADAR membaca daftar skill dan meminta jumlah bintang terbaru ke GitHub REST API saat halaman dimuat.
  • Klik item membuka halaman repo resmi GitHub — bukan salinan lokal, jadi selalu yang terbaru.
  • Tombol Racik di FORGE memakai identitas repo itu untuk menarik filenya sebagai draf.

07 Contoh use case

USE CASE 1 · Cari arah ide skill

  • Buka RADAR, perhatikan skill dengan bintang tertinggi (yang banyak dipakai tim).
  • Bedah polanya: format beres, deskripsi ringkas, langkah jelas.
  • Lanjut ke FORGE → telusur repo itu → Racik → sesuaikan jadi kebutuhanmu.

USE CASE 2 · Riset sebelum membangun

  • Kamu ingin membuat skill “cara buat proposal”.
  • Di RADAR cari tema proposal/template yang sedang ramai, buka repo-nya.
  • Lihat struktur yang dipakai mayoritas → bangun versi milikmu yang lebih pas untuk usaha lokal.

USE CASE 3 · Pantau apa yang sedang naik

  • Atur kebiasaan: buka RADAR tiap pekan, tekan REFRESH.
  • Catat skill yang naik signifikan.
  • Sebelum orang lain, racik versimu untuk kebutuhanmu.

08 Tanya-jawab yang sering

Apakah jumlah bintang itu karangan?

Tidak. Angka dibaca langsung dari GitHub API — data asli, bukan estimasi.

Kenapa klik item harus membuka tab baru?

Agar kamu tidak kehilangan posisi di aplikasi. Setelah meneliti di GitHub, tinggal kembali ke tab ini dan lanjut meracik.

Bagaimana mengubah skill populer jadi punyaku?

Gunakan Racik di FORGE untuk menariknya jadi draf, lalu tulis ulang isinya sesuai kebutuhanmu — adaptasi, bukan salin mentah.

Bintang tinggi selalu berarti bagus untukku?

Belum tentu. Bintang menandakan popularitas, bukan kecocokan dengan masalahmu. Ambil pola, sesuaikan isinya dengan konteksmu.

09 Glosarium

RADAR — modul yang menampilkan daftar skill populer dengan bintang asli GitHub.

Bintang (★) — penanda popularitas/jumlah yang menyimpan repo di GitHub.

Repo — tempat penyimpanan kode/berkas di GitHub.

REFRESH — tombol menarik ulang angka bintang terbaru.

Racik — tindakan mengubah repo publik menjadi draf skill di FORGE.

Pola — cara baku yang terlihat berulang di skill-skill bagus: struktur, bagian, bahasa.
