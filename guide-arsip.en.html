Complete Guide · Module 3

ARSIP — Collection & Account

ARSIP is home to every skill you compose in FORGE. Here you manage your collection and — optionally — connect an online account so your skills can travel to any device. This guide walks through each step in detail.

⏱ ≈ 6–7 min read🎯 All beginners🔐 Account optional, not required
01 · See your collection 02 · Create an account 03 · Log in 04 · Forgot password 05 · Sync across devices 06 · Log out / delete account 07 · Behind the scenes 08 · Use cases 09 · FAQ 10 · Glossary

Most important note: every core feature works even without logging in. The online account is only an extra layer for backup & cross-device sync. Skills saved on this device are not lost when you log in or out.

01 Open ARSIP & see your collection

1

Enter from the Home page

Click the "ARSIP — collection" card, or the ARSIP tab. Every skill you've saved from FORGE appears here as a list / row of collection items.

Search it: use the search box up top to filter by name or content in real time. What you can do with a skill: open (send it back to FORGE to edit), rename, copy, download as a SKILL.md file, or delete.

SUCCESS CHECK The skill you saved earlier shows up in the collection list.

02 Create an account (optional but recommended)

2

Register with email & password

Press "Sign up", fill in your email address and password, then submit. This account is used for cloud storage.

Security tips: use a strong, unique password (mix of letters, numbers, symbols). Your session lasts up to 30 days, so you don't need to log in again every day.

After registering: if it's a brand-new account, the app automatically shows a quick tour as a welcome — follow it to the end to get to know every module.

SUCCESS CHECK The status changes to "signed in", and the save-to-cloud button is now active.

03 Log in

3

Log in to use sync

Press "Log in", fill in your email & password. If correct, you're connected to your account and can save / pull skills from the cloud.

Caution: only log in on devices you trust. Use Log out if the device is shared, so your account isn't open anywhere careless.

SUCCESS CHECK Your account name / email appears as the signed-in status.

04 Forgot your password?

4

Reset via email

Click "Forgot password?" → enter the registered email → the system sends a 6-digit code to that email → enter the code → set a new password.

Why a code: to make sure only the email owner can change the password. The code expires in 15 minutes, so use it soon.

Haven't received an email? Check the spam folder, make sure the email is correct, then try again. If it still doesn't arrive, the app shows a fallback code right inside the page so you're never stuck.

SUCCESS CHECK After entering the code you can set a new password and log in.

05 Take your skills to another device

5

Save to the cloud, then pull it elsewhere

With the same account, skills you save to the cloud can be pulled / synced on another device. Great when moving from laptop to phone, or switching devices.

Why safer: your skill list no longer depends on a single device — there's a backup copy on the server.

SUCCESS CHECK Log in with the same account on a second device → the skill collection is available there.

06 Manage your account: Log out / Delete

6

Log out

Log out = stop being connected on that device. The local collection stays intact; you can log in again anytime.

7

Delete account

Delete account = removes your cloud data (skills stored on the server). Important: this only clears server data; the locally stored collection on your device stays safe.

Before deleting: make sure you've exported / saved locally every cloud skill you want to keep.

07 Behind the scenes

  • Local saving writes to device storage; cloud saving sends to the SKILL//ORBIT server through an authenticated API.
  • Passwords are stored with strong hashing; each reset code is unique and lasts 15 minutes.
  • Sessions last 30 days — you don't need to log in constantly, except after log out / reset / delete.

08 Use cases

USE CASE 1 · Moving between devices

  • On the laptop: compose a skill, SAVE, then also save to the cloud.
  • On the phone: open ARSIP → Log in with the same account.
  • Pull / inspect the skill — available right away.

USE CASE 2 · Backup before switching devices

  • Log in → make sure every skill is saved to the cloud.
  • Switch / format the device → log back in → pull everything back.
  • No skill is ever lost.

USE CASE 3 · Share a team collection

  • A skill is saved & backed up to the cloud.
  • A teammate logs in with the shared account → pulls the same skill.
  • Everyone uses a consistent working recipe.

09 FAQ

Is an account required?

No. Every core feature (Forge, Radar, local ARSIP, guides, tour) works without logging in. The account is only for backup & sync.

Are local skills lost if I delete my account?

No. Deleting the account only deletes server data. The locally stored collection on the device stays.

What if I forgot which email I registered with?

The reset code goes to the registered email; if you've forgotten which one that is, contact the app maintainer with proof of ownership.

How long does a login session last?

30 days. You won't be asked to log in repeatedly within that period.

Is my password secure?

Yes — passwords are stored hashed (not raw text) on the server, and sent over an encrypted connection.

10 Glossary

ARSIP — the collection module for every skill you've saved.

Cloud — server (internet) storage, accessed through an account.

Log in — connecting to your account to use sync.

Reset code — a temporary 6-digit (15-minute) code sent to email to change your password.

Session — how long your login lasts (30 days) before you must log in again.

Sync — matching your collection across devices through the cloud.
